# C4 Architecture Model
This project follows the C4 architecture model.

The architecture is documented in four levels:

## C1 - Context Diagram
High-level overview of the system and external actors.

See:
[c1-context-diagram.md](./c1-context-diagram.md)

## C2 - Container diagram
Shows internal system containers and external integrations.

See:
[c2-container-diagram.md](./c2-container-diagram.md)

## C3 - Component Diagram
Shows backend internal component interactions.

See:
[c3-component-diagram.md](./c3-context-diagram.md)

## C4 - Code Diagram
SHows detailed backend code structure and relationships.

See:
[c4-code-diagram.md](./c4-code-diagram.md)
